# Third-party components

- **OpenVR SDK** (Valve Corporation) - `deps/openvr/openvr_api.cs` (C# bindings, v1.14.15) and the native
  `openvr_api.dll` (x86 in `deps/openvr-win32`, x64 next to the screenshot tool). BSD 3-Clause License,
  https://github.com/ValveSoftware/openvr/blob/master/LICENSE
- **BepInEx 5** (BepInEx team) - not included; the installer downloads the official release.
  LGPL-2.1, https://github.com/BepInEx/BepInEx
- **HarmonyX / Harmony** - ships with BepInEx. MIT.
- **UnityPy** - Python package installed by the installer on request to patch `globalgamemanagers`. MIT,
  https://github.com/K0lb3/UnityPy
